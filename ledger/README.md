# 出納帳（スマホ用アプリ）

金額・区分（支出／収入）・内容を入力するだけで、出納帳を Excel（.xlsx）で書き出せるスマホ用 Web アプリです。
インストール不要・サーバー不要・オフラインでも動きます。

## 使い方
1. 区分（支出／収入）をタップ → 金額 → 内容 →「登録」
   - 日付は今日が自動で入ります（変更も可）
   - 内容は過去の入力が候補に出ます
2. 「Excelを送る」で共有メニューが開き、メール・LINE・OneDrive・ファイルなどへそのまま送れます
3. Excel には次の2シートが入ります
   - **出納帳**：日付／区分／内容／収入／支出／残高（残高は数式）
   - **月別集計**：月ごとの収入・支出・差引

## スマホに入れる（ホーム画面に追加）
このフォルダを GitHub Pages などで公開し、スマホでそのURLを開きます。
- iPhone（Safari）：共有ボタン →「ホーム画面に追加」
- Android（Chrome）：メニュー →「アプリをインストール」/「ホーム画面に追加」

### GitHub Pages での公開手順
リポジトリの Settings → Pages → Branch でこのブランチ（または master）と `/ (root)` を選んで保存。
数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/ledger/` で開けます。

## 注意
- データはスマホのブラウザ内に保存されます。機種変更やブラウザのデータ削除で消えるため、ときどき「Excelを送る」でバックアップしてください。
