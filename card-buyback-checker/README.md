# カード買取チェッカー

カードショップのショーケースを撮影すると、AI（Claude）がカード名・型番・値札の価格を読み取り、登録した**買取価格**と照合して「どれくらいお得か」を表示するスマホ向け Web アプリです。

## できること

| 機能 | 内容 |
|---|---|
| ショーケース読み取り | 写真（複数枚可）からカード名・型番・レアリティ・販売価格を抽出。読み違いはその場で修正できます |
| 買取表の登録 | ①買取表の写真・スクショを AI で読み取り ②CSV / スプレッドシートを貼り付け ③手入力。複数店舗を登録できます |
| 照合 | 型番が一致するものを優先し、なければカード名（表記ゆれ吸収）とレアリティで照合。複数店舗のうち**最高買取**を採用します |
| お得度 | **買取率 = 買取価格 ÷ 販売価格** と差額を表示。100%以上は「利益が出る」、しきい値（初期値85%）以上は「かなり割安」 |
| Web 買取相場 | 買取表にないカードは、ボタン1つで主要ショップの買取価格を Web 検索。結果はそのまま買取表に追加できます |

## 使い方

1. **設定** タブで Anthropic API キーを入力して保存
2. **買取表** タブで、売り先にしたいお店の買取価格を登録（店頭の買取表を撮るのが一番早いです）
3. **照合** タブで「ショーケースを撮影」→ 30秒〜1分で結果が並びます。並び順はお得度・差額・価格・写真順から選べます

撮影のコツ: 値札の数字と型番が読める距離で、ショーケース1段〜2段ずつ撮ると精度が上がります。ガラスの反射は斜めから撮ると減らせます。

## 起動

ビルド不要の静的サイトです。

```bash
cd card-buyback-checker
python3 -m http.server 8000   # または npm start
# → http://localhost:8000
```

スマホで使うには GitHub Pages などの HTTPS ホスティングに置いてください（カメラ起動とホーム画面追加に HTTPS が必要です）。

## テスト

```bash
cd card-buyback-checker
npm test
```

## 構成

- `matching.js` … 表記ゆれの正規化・照合・お得度計算・CSV 取り込み（純粋関数、`matching.test.js` でテスト）
- `claude.js` … Claude API 呼び出し（ショーケース読み取り / 買取表読み取り / Web 相場検索）。構造化出力で JSON を受け取り、拒否時は自動フォールバック
- `app.js` / `index.html` / `styles.css` … 画面

## 注意

- API キーはその端末のブラウザ（localStorage）にのみ保存され、Anthropic の API に直接送られます。個人利用向けの作りなので、共用端末や公開 URL で他人に使わせる用途には向きません（その場合はサーバー経由にしてください）。
- API 利用料がかかります。写真は送信前に縮小しています。
- AI の読み取りや Web 相場は誤ることがあります。購入前に値札と最新の買取表を必ず確認してください。
- 買取価格は状態（美品・キズあり）で変わります。買取表の「美品」価格と比較しているため、実際の買取額は下がる場合があります。
- 店内撮影はお店のルールに従ってください。
