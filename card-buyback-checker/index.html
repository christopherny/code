カード買取チェッカー

ショーケースを撮る → 買取価格と照合 → お得度がわかる

はじめに 設定 で API キーを入れ、買取表 に照合先の買取価格を登録してください。

1枚の写真に収まる範囲で、値札まで写るように撮ると精度が上がります。複数枚まとめて選択もできます。

    買取表を登録

    売り先にするお店の買取価格を登録します。複数店舗を登録すると、一番高い買取価格で比較します。

    1行に「カード名, 型番, レアリティ, 買取価格」（ヘッダー行あり・タブ区切りも可）。スプレッドシートからそのまま貼り付けOK。

    1件ずつ手入力
    カード名型番レア買取店舗

    設定

    キーはこの端末のブラウザにだけ保存され、Anthropic の API に直接送信されます。共用端末では使わないでください。

    買取率 = 買取価格 ÷ 販売価格。100% 以上なら買ってすぐ売っても利益が出ます。
